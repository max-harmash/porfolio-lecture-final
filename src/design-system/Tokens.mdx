# Токени

Єдине джерело значень — блок `@theme` у `src/app/globals.css`. Тут лише показ: значення беруться зі змінних CSS, тож сторінка завжди збігається з кодом. Назви токенів — за роллю, не за кольором. Стандартні кольори, розміри тексту й радіуси Tailwind скинуті: доступне тільки те, що є нижче.

## Шрифти

`font-mono` — Martian Mono: заголовки, меню, кнопки, мітки.

<Typeset fontFamily="var(--font-mono)" fontWeight={700} fontSizes={["var(--text-display)", "var(--text-heading)", "var(--text-title)"]} sampleText="Автоматизую рутинні процеси" />

`font-sans` — Geologica: основний текст.

<Typeset fontFamily="var(--font-sans)" fontSizes={["var(--text-lead)", "var(--text-body)"]} sampleText="Щоб люди ставили задачі й ухвалювали рішення" />

`font-hand` — Caveat: рукописні нотатки.

<Typeset fontFamily="var(--font-hand)" fontWeight={700} fontSizes={["var(--text-hand)"]} sampleText="це головне!" />

## Інше

- `aspect-cover` — пропорція обкладинки картки роботи (392 : 150 з макета).
- `aspect-portrait` — пропорція фото на першому екрані (332 : 403).
- `max-w-page` — ширина контенту сторінки, 1224px. Лише для розкладки сторінок.
- `gap-section`, `pt-section` — відстань між великими блоками сторінки, 72px. Лише для розкладки сторінок, у компонентах не використовуйте.
- `bg-grid` — фонова сітка 54 × 54 з макета.
- `border-thin` — тонка рамка 1.5px для мітки з номером.
